# LumeBox 订阅源

按板块提供漫画、美图、视频、影视与听书源。

## 订阅入口

| 入口 | 收录内容 | 源数量 |
| --- | --- | ---: |
| [漫画 / 美图](https://raw.githubusercontent.com/teng662858/LumeBox-Sources/main/comics) | 漫画与图片源 | 26 |
| [视频 / 影视](https://raw.githubusercontent.com/teng662858/LumeBox-Sources/main/videos) | 视频、影视、直播与听书源 | 27 |
| [总订阅](https://raw.githubusercontent.com/teng662858/LumeBox-Sources/main/all) | 漫画与视频全部分组，按板块导入 | 61 |

在 App 的源选择页点击「+」，选择订阅导入并粘贴对应入口的链接。
