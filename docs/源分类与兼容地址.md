# 源分类与兼容地址

小说源和小说订阅入口已于 2026-10-21 移除。App 的内容板块为漫画、视频、猫源。

| 类型 | 订阅入口 | 脚本目录 |
| --- | --- | --- |
| 漫画 | comics | comic/ |
| 美图 | photos（也纳入 comics） | photo/ |
| 影视 | movies（也纳入 videos） | movie/ |
| 视频 | videos | video/ |
| 听书 | audiobooks（当前为空） | audiobook/ |

总订阅 `all` 只包含漫画和视频订阅。旧漫画、视频中文订阅及目录内清单保持兼容；小说清单已删除。

漫画与视频旧位置的四个脚本是兼容镜像，正式清单指向 photo/、movie/；维护时同步镜像，避免旧单脚本地址失效。
