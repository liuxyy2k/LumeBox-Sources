# 源分类与兼容地址

小说源和小说订阅入口已于 2026-10-21 移除。App 的内容板块为漫画、视频、猫源。

| 类型 | 订阅入口 | 脚本目录 |
| --- | --- | --- |
| 漫画 / 美图 | comics（51 个源） | comic/、photo/ |
| 影视子集 | movies（3 个源，已纳入 videos） | movie/ |
| 视频 / 影视 | videos（50 个源） | video/、movie/ |
| 影视扩展 | videos-hd（7 个源） | video/ |
| 成人视频扩展 | videos-18plus（1 个源） | video/ |
| 美图子集 | photos（1 个源，已纳入 comics） | photo/ |
| 听书 | audiobooks（4 个源，已纳入 videos） | audiobook/ |

总订阅 `all` 按漫画、视频两个板块导入，展开 `comics`、`videos` 及两个视频扩展清单，共 109 个独立源。完整清单见[源目录](源目录.md)。旧漫画、视频中文订阅及目录内清单保持兼容；小说清单已删除。

漫画与视频旧位置的四个脚本是兼容镜像，正式清单指向 photo/、movie/；维护时同步镜像，避免旧单脚本地址失效。
