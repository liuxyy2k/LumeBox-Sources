# 源分类与兼容地址

六个独立订阅入口与正式脚本目录：

| 类型 | 内容定义 | 订阅入口 | 脚本目录 |
| --- | --- | --- | --- |
| 小说 | 文字阅读 | novels | novel/ |
| 听书 | 含可播放音频的有声内容 | audiobooks | audiobook/ |
| 漫画 | 漫画作品 | comics | comic/ |
| 美图 | 网络美图、写真图库 | photos | photo/ |
| 影视 | 网络影视站 | movies | movie/ |
| 视频 | 网络小视频及现有泛视频源 | videos | video/ |

当前没有独立听书脚本，听书清单为空，不把纯文字小说或助眠视频误归为听书。
现有直播、助眠及成人动画源继续归视频，未将它们标为影视站。

App 内部仍保持小说、漫画、视频三个数据板块，每个板块展示两类源；分组不更改源 ID 或板块 category，避免已有书架、订阅及播放记录丢失。新听书源接入时还须提供实际音频解析及播放支持，空目录不代表已有音频能力。

漫画与视频目录中旧位置的四个文件是兼容镜像，供已经保存的单脚本订阅地址继续更新，正式六类清单只指向 photo/、movie/ 的正式文件；维护时须同步镜像。旧三份中文订阅入口保留原三板块合集，六类新入口之间不重复。
