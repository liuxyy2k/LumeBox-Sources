# 订阅地址迁移

根目录不再平铺各类清单。所有入口在 `subscriptions/`，索引数据在 `metadata/`；脚本 ID 和有效脚本原地址不变。

新版 APP 会把已保存的旧官方清单地址迁移到新地址，保留启用状态、成员与排除记录。旧版 APP 不认识迁移规则，需要升级或重新填写 README 的新地址。迁移表见 `metadata/legacy-paths.json`；这不是服务器 HTTP 重定向，直接用浏览器打开已删除的旧文件地址仍会 404。

选择国内 CDN 线路时，总订阅、分类清单与脚本均走 CDN，不再把子链接指回 raw.githubusercontent.com。原站线路仍可选。两条线路的 ID 集合一致，无需同时导入。

已删除的重复脚本记录在 `metadata/removed-duplicates.json`。需要查看历史内容时使用 Git 历史。封面、图标和播放的实时检测独立进行，不由清单目录的检查结果代替。
