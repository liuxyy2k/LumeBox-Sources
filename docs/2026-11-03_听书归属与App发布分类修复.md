# 听书归属与 App 发布分类修复

截图中的有声订阅进入漫画板块，但旧脚本仍声明 `category: video`，旧版 App 因跨板块校验拒绝导入。本次只修正身份元信息，不改站点解析、请求、付费或播放规则。

| 源 | 新版本 |
| --- | --- |
| 13听书网、听书吧、悦听吧、麒麟听书 | 1.0.3 |
| 夜读小说听书 | 1.0.1 |
| 小黄书听书 | 1.0.2 |
| 悦听（video/悦听.js 兼容路径） | 1.0.1 |

以上源的头部和运行时对象统一使用 `category: comic`、`mediaType: audio`，保持原 ID。总订阅仍把有声清单放在漫画板块，无需用户编辑脚本。

生成器与 App 上传校验同步调整：音频类型优先于影视内容标签；阅读源不再被强制要求影视/成人视频分类。GitHub App 发布脚本也接受同一套声明，避免手机校验成功、服务端又拒绝。

验证：四个生成听书源离线契约通过；小黄书家族快照 17 项通过；源分类、App 发布、CDN 刷新及 Python 目录测试通过；`python tools/build_catalog.py --check` 无变化。未据此宣称各源当前网络或媒体播放全部可用。

发布后需实际下载 GitHub 与国内 CDN 的七份脚本，核对版本、category、mediaType 与 SHA-256 一致。App 的自动归类、发布后自动安装和简洁结果展示需安装配套的新 App 构建；脚本归属修复通过重新同步订阅获取。
