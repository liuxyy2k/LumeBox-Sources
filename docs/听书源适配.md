## 导入

在 App 视频板块的源选择抽屉点击“+”，添加订阅：

```text
https://raw.githubusercontent.com/teng662858/LumeBox-Sources/main/audiobooks
```

已订阅 `videos` 或旧版 `视频订阅.js` 的用户，更新对应订阅即可获取这四站。总订阅 `all` 通过 `videos` 同样包含它们。新增脚本无需重新打包 App；网页渲染需要已有的 iOS 网页宿主能力。

## 目录与搜索设计

- 麒麟听书、13 听书和悦听吧的长目录按站点公布的真实分段范围建立章节位置，播放某集时才读取对应目录页，避免一次下载几十页而触发 App 的 10 秒脚本预算。已加载段使用真实标题，其他段显示集号；不推算源站音频 ID。
- 13 听书不保存会变化的目录签名地址；章节 ID 记录书籍、页号与段内位置，重新从详情查当前目录入口。
- 搜索结果必须包含查询书名，页面底部的其他推荐不会混入。站点未命中则返回空结果；验证页和 HTTP 错误则明确报错。
- 音频 URL 每次播放重新解析，保留对应 Referer 和 User-Agent。悦听吧使用宿主现有 AES、Base64、MD5 工具，不加载外部加密库或保存账号密钥。

## 播放参数兼容说明

13 听书的原生请求分支沿用网页公开的 `_b`、`_p`、`_c`、`_d` 字段，向 `/api/mapi/play` 提交当前章节；`sc` 为当前页面值，`sp` 按播放器的字符映射生成。遇到原生请求持续触发网页验证时，App 分支由网页播放器自行完成这一过程，等待 `audio[src]` 后返回真实地址。

悦听吧 `/api/app/docs-listen/{id}/ting-with-efi` 返回当前章节描述，公开播放器中的 `assl` 配置给出服务器，`efi` 使用该章节 ID 和创建时间派生的 AES 参数解码。临时 URL 按站点播放器规则生成并保留十分钟时效。若接口返回限制或无音频，脚本停止，不绕过源站账号、验证码或收费限制。

## 维护与复验

源文件由模板生成，修改模板与公共辅助文件后运行：

```powershell
node tools/build_audiobooks.cjs
node tools/audiobook_test.mjs
node tools/audiobook_test.mjs --live --only=悦听吧
```

离线回归覆盖列表书名、排除无关搜索推荐、分段目录、跨页章节解析、两种麒麟播放结构、听书吧线路与请求头、13 听书网页音频分支和验证提示。线上检查顺序为分类、首页、列表、详情、目录、音频 Range 与一次书名搜索，避免连续搜索触发限流。

本次浏览器验证另外确认了 13 听书的完整目录及 Range 音频响应；普通 Node HTTP 检查不能替代 App 的 WebKit，也不会自动处理图片验证码。

App 侧音频标记、图源契约及桥接回归 31 项通过。仓库原有全量回归仍有两项历史失败：`大人漫画.js` 的首行与运行时版本不一致，以及旧中文清单与现有总清单覆盖范围不一致。本次未修改这些无关源或旧清单覆盖范围；新增四站的独立订阅、视频清单包含关系回归通过。
