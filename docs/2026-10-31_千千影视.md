# 千千影视

`movie/千千影视.js` 读取千千影视公开的首页推荐、电影/连续剧/综艺/动漫列表、筛选项、站内搜索、作品详情和分集。域名 `qqys01.com` 会跳转至 `www.qqys01.com`，因此不登记为独立镜像；没有验证到其他同内容镜像。

播放地址来自公开播放页中站点播放器配置：公开 HLS 直链可由 App 原生播放，腾讯/爱奇艺分享页交回网页播放器。站点明确标注 VIP、积分或付费的分集会报可读错误；本源不使用解析服务、不调用权限接口、不绕过站点授权。多个公开线路会在选集列表中显示，部分旧线路可能返回 403/404。

## 验证

- 主站：首页、电影/连续剧列表、搜索、详情和播放页均返回 HTTP 200。
- 源检查器：默认、连续剧和动作筛选链路通过；搜索“长征”返回 7 项；各筛选项映射到站点真实 URL。
- 播放探活：抽样 JS、BF、DB 线路均有 `200 + #EXTM3U`；LZ/FF 样本存在 404/403。
- 封面探活：`image/jpeg`，HTTP 200。
- `snapshots/qqys01_fixture.json` 保留脱敏后的结构回归样本。App 原生 QuickJS 用例覆盖分类、搜索、筛选、分页、公开播放解码和积分限制拒绝。
- 搜索“我”的第 2 页实测与首页不同，QuickJS 回归使用该页的真实结构；分集快照完整保留 364 条，未按 300 条截断。
- `flutter test --no-pub test/source_scripts_native_test.dart --plain-name 千千影视` 和 `dart analyze test/source_scripts_native_test.dart` 均通过；目录生成 `--check` 为 0 变化。
